《螺旋の門》— BWV 565を読み直し、別の答えを出す

CLAUDE · ANALYSIS & COMPOSITION

新作《螺旋の門》（ホ短調・67小節）は、BWV 565を音符データから分析し直して書きました。原曲の形（小節数や区切り）はなぞらず、原曲がその書法を選んだ理由（緊張の作り方、主題の作り方、和音の使い方）を受け継いでいます。BWV 565にない技法（反行形、ストレッタ、長調化、動機の同時進行）も加え、暗い短調から長調の光へ抜ける別の結末を用意しました。

01 — BWV 565を音符データから読む
位置データから読み取れること音楽理論上の意味
冒頭
第1〜3小節		属音Aの呼びかけ（モルデント）→ 32分音符の下行 → C♯–D。第2〜3小節では、主音Dの持続低音の上にC♯–E–G–B♭が一音ずつ積まれる。主音ではなく属音から始め、主和音への到達を遅らせる。減七の和音を「足し算」で組み、緊張を目に見える形で増やす。
トッカータ
第4〜10小節		D–E–C♯の三連音型を両手がオクターヴで反復。第8〜10小節は分散和音が順次下行する（6の和音の連続）。音型の反復で推進力を作り、和声は下行ゼクエンツで一気に動かす。
第13〜15小節左手がA4を16分音符で打ち続け、右手が下行音階を重ねる。これはフーガ主題（Aの反復と下行線の交替）の予告。トッカータとフーガは動機でつながっている。
フーガ主題
第30小節〜		軸音Aと、B♭–A–G–F–E–D–C♯–Dと下る線が16分音符で交互に現れる。この「軸音交替」型の音列を、フーガ部分だけで20か所検出。単旋律なのに2声に聞こえる（暗示的多声、バリオラージュ）。ヴァイオリン的な書法と言われる理由。
応答
第32小節		2回目の提示はD音を軸にしたト短調。通例の属調（イ短調）ではなく下属調への応答。BWV 565の珍しい特徴。
テクスチュアフーガの大半は2〜3声。足鍵盤は全3,651音中329音だけで、第31〜51小節と第58〜85小節は完全に休止。厚い対位法より、音域と手鍵盤の交替（エコーなど）で変化を作る即興的なフーガ。
終結
第127〜143小節		減七の連打と休止、Presto・Vivaceの走句、Molto AdagioでGm→Dmの変格終止。最後の和音は短3度F♮を含む。修辞的な「沈黙」と、短調のままの暗い閉じ方。

半小節ごとの音高集合で数えると、BWV 565は286区間に110種類の響きを持ちます。旋律の動きの35%が半音・全音の順次進行です。

02 — 《石の回廊》が退屈に聞こえる理由（数値比較）
指標BWV 565石の回廊螺旋の門
まったく同じ小節の繰り返し4210
響きの種類（半小節ごとの音高集合）110 / 286（38%）57 / 286（20%）89 / 134（66%）
順次進行（半音・全音）の割合35%17%38%
3〜5度の跳躍の割合40%60%37%

《石の回廊》の大部分は、16分音符の分散和音（根音–5度–3度–5度型）＋4分音符の左手＋2分音符のペダルという同じテクスチュアの繰り返しです。そのため旋律は跳躍ばかりになり（順次進行17%）、和声も2拍ごとに変わるだけです。独立した旋律が絡む対位法がほとんどなく、原曲の区切りは写しても書法は受け継いでいません。小節数を原曲と同じ143に固定したことも、中身の薄さを目立たせています。《螺旋の門》は長さを原曲に合わせず、すべての小節に役割を持たせることを優先しました。

03 — 原曲の技法は、新作でこう発展させた
BWV 565の技法《螺旋の門》での扱い
属音からの呼びかけ＋装飾＋急降下属音Bの呼びかけ。モルデントを回音B–C–B–A♯–Bに置き換え、A♯減七で急降下。第2小節は主音Eで応答し、フリギアのF♮で陰を付ける。この回音が全曲の動機になる。
持続低音の上に減七を積む低音Cの上にフランス増六（C–E–F♯–A♯）を一音ずつ積み、全声部が半音か同音で属和音Bへ解決。減七より強い「引力」の和音で、フーガの頂点（第54小節）で再び現れる。
三連音の反復音型両手が交互に受け渡す16分三連の「滝」。低音はEからEへ1オクターヴを半音ずつ下るラメント・バス（passus duriusculus）。後半は書法を変え、掛留を含む溜息の旋律にする。
減七の和音の多用減七の対称性そのものを主題にした。同じ音集合｛C・D♯・F♯・A｝を4通りに読み替え、ホ短調→ト短調→変ロ短調→嬰ハ短調→ホ短調と短3度ずつ螺旋状に転調する（第11〜15小節）。曲名の由来。
トッカータでフーガ主題を予告足鍵盤独奏（第16小節）とレチタティーヴォ（第22小節）で、フーガ主題をそのまま先に聴かせる。
暗示的多声の主題新主題は3つの要素を組み合わせた。①主和音の上行分散（E–G–B）②トッカータの回音（C–B–A♯–B）③16分音符の尾部。尾部は、半拍ごとの骨格音がE–D♯–D–C♯–C–Bと半音階で4度下る。
（固定されない対旋律）二重対位法で書いた固定対旋律を加えた。低音でA–A♯–Bと昇り、B–A♯–A–Gと下って、主題の半音階と10度で並ぶ。上下を入れ替えても成立する。
下属調への応答属調（ロ短調）の正規の応答で4声の提示部を作り、最後を足鍵盤で締める。足鍵盤が主題を受け持つ箇所では、主題を低音として和声付けし直している。
ゼクエンツと転調のエピソードエピソードは3種類。①主題尾部による五度圏のゼクエンツ（Bm–Em–Am–D7→G）②右手forte／左手pianoのエコー ③低音がD–D♯–E–E♯–F♯と半音ずつ上り、減七のアルペッジョと主題頭部が反行するゼクエンツ。
（BWV 565にない技法）長調化（ト長調。同主短調の和音B♭・Cmを借用）、反行形（イ短調。回音のA♯がナポリのB♭に変わる）、ストレッタ（半小節差で主題を重ねる。主調と属調で2回。平行5度を避けるため先行声部を切り上げ）、動機の同時進行（最終提示で、足鍵盤の主題の上にトッカータの呼びかけ）。
短調の変格終止最終主題の最後の音をEからCに曲げて偽終止にし、レチタティーヴォ、属音保続上のプレストへ。最後のコラールでは、ラメント低音の上で主題頭部を4倍に拡大し、V7→Iのピカルディ終止（ホ長調）と変格終止で閉じる。暗から明へ。

主題、対旋律、エピソードの動機、トッカータの音型、全体の和声進行と転調計画は設計して書いています。フーガの一部の内声（自由声部）は、和声進行と対位法の規則を満たす候補を探索して決めました。規則は、強拍の協和、平行5度・8度の回避、掛留の予備と下行解決、声部の交差の回避などです。全曲を検査し、フーガ部分に平行5度・8度がないことを確認しています。

04 — 聴きどころへ移動

作曲：Claude（Anthropic）。本依頼のための新作です。音符データをHTMLに固定収録しているため、再生のたびに曲が変わることはありません。「表情をつける」は区間ごとのテンポとフェルマータを反映します。「装飾音」は第23小節のB4と第48小節のD♯5のトリルを展開します。「均一テンポ」は♩72です。MIDIは均一テンポ・装飾展開なしの音符データです。

《石の回廊》— 原曲を読み、新しい曲へ

CHATGPT · ANALYSIS & COMPOSITION

新作《石の回廊》は、BWV 565の自由なトッカータ → 模倣的なフーガ → レチタティーヴォとコーダという大きな構成を、添付データと同じ143小節・572拍でたどります。調はニ短調からト短調へ。旋律・対旋律・各区間の和声を新しく作り、原曲と区間ごとに聴き比べられるようにしました。

01 — 原曲の音楽理論と、新曲への応用
構成（添付版の位置）BWV 565の読み取り《石の回廊》での実現
トッカータ
第1〜30小節途中		オクターヴの呼びかけ、休止、フェルマータ。減七の和音とペダルの持続音、急速な分散音型。自由な修辞的様式（stylus phantasticus）。GからB♭へ跳躍する新しい呼びかけを音域を変えて反復。Gの低音上にF♯–A–C–E♭の減七を重ね、Dの属和音へ。手鍵盤の受け渡しと急速な三連音型を展開。
フーガ提示
第30小節第3拍〜		Aの反復と動く音を交互に置く16分音符主題。単旋律の中に二つの線を感じさせ、別声部の応答と対旋律へつなぐ。G–A–B♭–Cへ上昇する骨格を持つ2小節の新主題。Dなどの反復音との交替は受け継ぐ。左手の単独提示 → ニ短調の応答 → ト短調の再提示へ。
ペダル主題
第52小節〜		主題を足鍵盤へ移し、音域と声部の役割を交替させる。新主題をG1からの足鍵盤に提示。右手・左手の長い音価の対旋律と重ね、主題を明瞭にする。
手鍵盤エピソード
第74〜108小節		手鍵盤中心の軽いテクスチュア。反復音型、模倣、ゼクエンツと転調で長い展開を支える。足鍵盤を休ませ、主題を変ロ長調・ハ短調・ニ短調・ト短調に配置。Gm–Cm–F–B♭–E♭–A°–D–Gmなどの五度圏進行と、上下の手の役割交換を用いる。
回帰と収束
第109小節〜		主題回帰と低音の支えによってフーガを収束させ、自由な終結部へ移る。右手 → 左手 → 足鍵盤へ主題を回帰。第119小節から足鍵盤の主題を2倍の音価に拡大し、Dの属音ペダルで緊張を高める。
レチタティーヴォ〜終結
第127小節第3拍〜143小節		独奏的な走句、休止と和音の対照。Presto、Vivaceを経てMolto Adagioへ。添付版の最後はF♮を含むニ短調。冒頭の動機を自由な独白として回想。急速部を経て、Cm → Aø7 → Gm/D → D7 → Gm。GからF♯への4–3の掛留解決と低音D→Gで閉じ、B♭を含む短調の響きを保つ。

位置は添付HTMLの演奏用データに準拠。第30・127・133小節では途中の拍から区間が変わります。小節番号と主要な区切りを共有し、各小節の音符数や声部配置は新しく設計しています。

02 — 新しい主題と、聴き分け方

主題の最初の1小節は、G–D–B♭–D ｜ A–D–F♯–D ｜ B♭–D–G–D ｜ C–E♭–G–E♭。縦線は拍の区切りです。2小節目でB♭–A–B♭–Gへ戻ります。16分音符の主題に、主に4分音符の対旋律を組み合わせています。

ボタンは新曲の該当位置へ移動します。再生中はそのまま続行、停止中は▶で開始。拡大主題はこの新作に加えた展開技法です。トッカータの自由な音型と、フーガの規則的な主題の違いにも耳を向けてください。

03 — 新曲のデータと保存

作曲：ChatGPT。本依頼のための新作です。音符データをHTMLに固定収録しており、再生のたびに曲が変わることはありません。合成音源・ピアノロール・解説を含め、ネット接続なしで使えます。

新曲の「表情をつける」は区間ごとのテンポと休止を反映します。「装飾音」は冒頭3回の呼びかけに下方補助音を加えます。「均一テンポ」では♩72です。MIDIは均一テンポ・装飾展開なしの音符データで、選択中の音色や残響は含みません。

BWV 565の原資料・操作ガイド・検証
